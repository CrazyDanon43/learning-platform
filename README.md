# Учебная платформа (Лабораторная работа № 3)

Одностраничное React-приложение учебной платформы: лекторы, партнёры, информация о проекте и форма заявки. Проект является базой для ЛР № 3: внешний разработчик добавляет новый функционал через Pull Request.

## Стек и версии

| Технология | Версия |
|------------|--------|
| React      | 19.2.x |
| ReactDOM   | 19.2.x |
| Vite       | 8.3.x  |
| Node.js    | 18+ (рекомендуется 20 LTS) |
| ESLint     | 10.x   |

Язык — JavaScript (JSX), модульная система — ES Modules (`"type": "module"`).

## Установка и запуск

```bash
# 1. Клонировать репозиторий
git clone <ссылка-на-репозиторий>
cd learning-platform

# 2. Установить зависимости
npm install

# 3. Запустить dev-сервер
npm run dev
# откроется на http://localhost:5173

# Прочие команды
npm run build     # продакшн-сборка в dist/
npm run preview   # предпросмотр сборки
npm run lint      # проверка ESLint
```

## Данные и роутинг

- **Данные** лежат в `src/lab2/data/` — это JS-модули с константами (`lecturers.js`, `partners.js`). Никакого бэкенда и БД нет; при необходимости новых записей данные добавляются прямо в эти файлы по существующему формату объектов.
- **Роутинг** — клиентский, без `react-router`: переключение разделов происходит через `useState` в `src/lab2/PlatformPage.jsx` (поле `activeSection`: `home` | `partners` | `about` | `lecturers`), а навигация в `Header` вызывает `setActiveSection`. Прямых URL-маршрутов нет — при добавлении новых страниц следует расширять тот же механизм либо мигрировать на `react-router`.

## Для разработчика нового функционала (ЛР № 3)

1. Клонируйте репозиторий, создайте ветку `feature/<название>`.
2. Вопросы автору фиксируйте письменно в онлайн-таблице (дата, содержание, статус).
3. Готовую функцию пришлите одним Pull Request в `main`.
